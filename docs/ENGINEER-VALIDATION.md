## Deployment inputs and scope

The software tests use isolated profiles and synthetic collectors where stated. They do not certify an ISP/router route or a team's actual pit rules. Driver packages need a hostname/address reachable from the driving PCs. The workstation reports each authenticated collector's connection independently of game telemetry so the team can see that connection before entering the car.

Actual event duration, extra-lap rule, pit-entry location, measured service/transit times, driver limits and tyre allocation are engineering inputs. Their confirmation state is visible in the UI. A stream alone cannot supply driving-seat resources; the collector runs on each driving PC.

Native references contain resampled distance, speed, inputs and available resources. They remain reference-only and do not train consumption or automated technique advice. Spatial racing-line and wheel traces are available from live/app recordings; this native importer does not import those channels. Original upstream `/legacy` UI and upstream lint findings are outside the new receiver's checked workflow.
